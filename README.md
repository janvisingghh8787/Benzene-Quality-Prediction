# 🧪 Benzene Quality Prediction using Machine Learning

## 📌 Project Overview
This project focuses on predicting the **quality of Benzene** using Machine Learning regression models.  
The objective is to build a data-driven model that accurately estimates benzene quality based on input features from refinery process data.

This project demonstrates data preprocessing, exploratory data analysis (EDA), model building, and performance comparison of multiple regression algorithms.

---

## 🎯 Objective
To develop a machine learning model that:
- Predicts benzene quality accurately
- Compares multiple regression algorithms
- Identifies the best-performing model
- Improves industrial decision-making using data analytics

---

## 📈 Model Evaluation Metrics
The performance of each model was evaluated using:

- **MAE (Mean Absolute Error)**
- **MSE (Mean Squared Error)**
- **RMSE (Root Mean Squared Error)**
- **R² Score (Coefficient of Determination)**

### 🏆 Best Model:
Random Forest Regressor achieved the best performance with:
- R² Score ≈ 0.81
- Lowest prediction error among tested models
